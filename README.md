# GamerZone

Web de una tienda de componentes gaming hecha en clase (DAM, Davante Medac Nova) con **HTML** y **CSS**: tienda, comparativa y ranking de componentes, presupuesto, blog de noticias, contacto, FAQ y contenido multimedia (audio y vídeo).

**Demo:** https://jaaviidiaz.github.io/GamerZone/

## Estructura

Todo el código está en `Equipo_2_BDAM/Equipo_2_BDAM/`:

- `pagina1.html` … `pagina12.html` — las páginas de la web
- `css/todo.css` — hoja de estilos común
- `imagenes/` — imágenes de productos, noticias y equipo
- `audio_e_video/` — música y vídeo
